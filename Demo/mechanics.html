Exact arithmetic

The time field covers about 34.8 years from epoch. Every call reads Date.now. Neither a cached clock nor invented future time is used. This is a new ID format; legacy rounded IDs cannot regain lost bits.

  1. Pin and deploy the same package version. Commit package.json and package-lock.json. Use npm ci in deployments. Update the pinned version deliberately, test it, and roll it out across services. npm distributes code; it does not synchronize clocks, configuration, or generated IDs.
  2. Choose one shared epoch. Store it in shared deployment configuration and keep it stable. Consumers need that same epoch to decode IDs. An ID does not include its epoch or npm version.
  3. Assign each concurrent generator its own machine ID. Use an explicit deployment allocation from 0 to 1023. Two replicas of one service also need distinct IDs; do not randomly select IDs or give every replica the same environment value.
  4. Synchronize host clocks. Use your infrastructure’s time synchronization service (such as NTP). Monitor clock skew and rollback. Particle throws ERR_CLOCK_ROLLBACK until the clock catches up. The ninth issuance per machine/epoch in one millisecond throws ERR_SEQUENCE_EXHAUSTED. The library never waits or moves time forward itself.
  5. Initialize once per process. Particle remains a shared singleton. Configure it at startup. Each active process needs a unique machine allocation. Before reusing an allocation after restart, ensure the clock has passed its persisted last-issued timestamp; a reload alone resets in-memory state. For logs or events, pass the generated ID to other services instead of regenerating it there.

// Run once at service startup (Node 26+).
require('@sschiau/particle')
const generator = globalThis.Particle

const machineId = Number(process.env.PARTICLE_MACHINE_ID)
const epoch = Number(process.env.PARTICLE_EPOCH_MS)
if (!process.env.PARTICLE_MACHINE_ID?.trim() || !Number.isInteger(machineId) || machineId < 0 || machineId > 1023) {
  throw new Error('Assign this process a unique machine ID from 0 to 1023')
}
if (!Number.isSafeInteger(epoch) || epoch < 1000000000000 || epoch > Date.now()) {
  throw new Error('Set a stable, shared epoch in milliseconds')
}
generator.machineId = machineId
generator.epoch = epoch

// In a request or event handler:
const id = generator.generateParticle()
const timestamp = generator.timeFromParticle(id)
console.log({ id, timestamp })
JSON by default. Binary when both ends opt in. The safe integer IDs round-trip exactly as JSON numbers. The optional binary adapter sends the same Numbers in an explicit byte format. Neither encoding allocates machine IDs or protects unsafe restarts. At 8 IDs/ms, 100,000 unique outputs need at least about 12.5 seconds per generator. Always keep the epoch/format namespace with stored data.
